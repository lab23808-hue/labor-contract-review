# Dense / BM25 / Dense+BM25+RRF 检索策略对照实验报告
运行时间（UTC）：2026-10-10T19:09:53.300358+00:00
## 目标
验证 Dense 向量检索漏掉的相关法条（典型案例：'自愿放弃社保换现金补偿'场景下《劳动合同法》第十七条在 Top-20 内完全不出现）能否被 BM25 词面匹配找回，以及 Dense+BM25 用 RRF 融合后整体指标是否更好。
## 控制变量
- candidate_k=20（每个通道的候选深度），final_top_k=[5, 10, 20]（评估截断深度），rrf_k=60（固定值，本轮不做参数搜索）
- 分词器：char_bigram (jieba not installed)
- 样本/场景：188 条有效样本，47 个独立 (query, 标签) 场景
- Dense 通道来源：rerun（原因：知识内容无法证明一致，按规则不允许复用）
- 知识库一致性核验（BM25 用的切片 vs 官方 Chroma 实际存着的切片）：{'checked': True, 'official_doc_count': 26, 'freshly_split_doc_count': 26, 'content_match_exactly': True, 'ids_match_exactly': False, 'id_mismatch_likely_due_to_hash_scheme_change': True, 'problems': ['内容完全一致，但 _evidence_id() 算出的哈希 id 全部不同——大概率是官方库写入时用的是旧版 _evidence_id()（2026-10-10 加入 part 字段之前的 3 段哈希），而不是内容真的变了；这不影响 BM25/Dense/RRF 的检索正确性（三个通道都按 (source, article) 匹配，不依赖这个内部 id），只是 id 本身的哈希算法版本和当前代码不一致，供参考。']}
