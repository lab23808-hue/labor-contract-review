## 3. 已知失败案例逐条核实（真实数据，working=37条Evidence，括号内为baseline=26条Evidence对照）

### 3.1 工作地点单方调整 与 第二十六条 的双通道漏检 —— **确认存在，知识覆盖问题待核实**

- Query：`"工作地点\n乙方工作地点为深圳市。甲方可以根据经营需要随时调整乙方工作地点，乙方应无条件服从。"`
- 相关法条：`[劳动合同法-第三十五条, 劳动合同法-第二十六条]`，3个样本（3份不同合同）
- 第三十五条：Dense rank=1（working）/1（baseline），BM25 rank=18（working）/10（baseline），RRF rank=7（working）/3（baseline）——命中但排名随知识库规模波动
- **第二十六条：Dense rank=None，BM25 rank=None，RRF rank=None——working与baseline两个知识库版本都是双通道完全未召回（candidate_k=20内都不存在）**
- 判定：这是**candidate_k=20范围内的真实候选未召回**，不是"排名靠后"。需要人工核实该法条文本是否确实已被`KnowledgeLoader`正确切分进working/baseline知识库（本文件未做`data/knowledge/`原文逐条exists检查，不能排除是知识覆盖问题，也不能排除是Dense/BM25对该query表述的语义/关键词匹配本身较弱——两种可能都未被本次分析证实或排除，标记为**待核实（UNVERIFIED_ROOT_CAUSE）**）。
- 标准答案核验状态：UNVERIFIED（188条标签样本尚未逐条人工核验）。

### 3.2 社保放弃及现金补偿 —— **部分命中，第二十六条排名靠后（非候选未召回）**

- Query：`"社会保险\n经双方协商一致，乙方自愿放弃由甲方缴纳社会保险，甲方每月向乙方支付人民币800元作为补偿。"`
- 相关法条：`[劳动合同法-第二十六条, 劳动合同法-第十七条]`，3个样本
- 第二十六条：Dense rank=17（working）/14（baseline），BM25 rank=17（working）/14（baseline），RRF rank=16（working）/15（baseline）——**在candidate_k=20内能检索到，但远未进入Top5/Top10，属于排名靠后**
- 第十七条：Dense rank=None（working和baseline都是None），BM25 rank=1（命中），RRF rank=17（working）/18（baseline）——说明BM25单独使用对这条命中很好，但RRF融合反而把排名拉差（RRF排名比BM25单独排名差很多，这是RRF数学性质决定的——见`docs/RAG_EXPERIMENTS.md`问题记录6）
- 判定：**排名靠后问题，不是知识覆盖问题**（两条法条都在candidate_k=20内存在）。
- 标准答案核验状态：UNVERIFIED。

### 3.3 延迟支付工资与免责 —— **BM25 Top10命中、Top5未命中，Dense完全未召回**

- Query：`"劳动报酬\n乙方正式工资为每月人民币15000元，甲方可以根据资金情况延迟支付，乙方不得因此追究甲方任何责任。"`
- 相关法条：`[劳动合同法-第三十条, 劳动合同法-第二十六条, 劳动合同法-第八十五条]`，3个样本
- 第三十条：Dense rank=2，BM25 rank=1，RRF rank=1——全部命中Top5
- **第二十六条：Dense rank=None，BM25 rank=9（working）/6（baseline），RRF rank=15（working）/10（baseline）**——BM25在working口径下排名从baseline的6名退到working的9名（仍在Top10内，Top5未命中两个版本皆然），Dense两个版本都完全未召回
- 第八十五条：Dense rank=4，BM25 rank=2，RRF rank=3——全部命中Top5
- 判定：该场景3条相关法条中2条稳定命中Top5，第二十六条是唯一的薄弱点，且Dense通道对第二十六条完全没有识别能力（两个知识库版本一致），BM25能检索到但排名不够靠前。**这是检索排序问题，不是知识覆盖问题**（第二十六条确实在candidate_k=20内被BM25找到）。
- 标准答案核验状态：UNVERIFIED。

### 3.4 加班费已包含在工资内 —— **BM25排名很差(Top20边缘)，Dense命中Top5，与项目一贯"BM25更强"模式相反**

- Query：`"工作时间和休息休假\n甲方可根据经营需要安排乙方加班，加班不另行支付加班费，已包含在乙方月工资内。"`
- 相关法条：`[劳动合同法-第三十条]`，4个样本
- Dense rank=4（命中Top5），**BM25 rank=20（working，candidate_k=20的最后一名，几乎未召回）**，RRF rank=9（未命中Top5，命中Top10）
- 判定：这是本次分析中**唯一一个BM25排名明显弱于Dense**的已知案例，与"char_bigram BM25整体排序质量优于Dense"的全局结论方向相反。可能原因（**未经进一步验证，不作为确定结论**）：该query的关键词（"加班费""已包含在工资内"）可能与第三十条原文的字面重合度低于其他候选法条，导致char_bigram字符级匹配劣势放大；这只是一个未验证的假设。
- 标准答案核验状态：UNVERIFIED。

### 3.5 无理由解除合同 —— **多标签场景，各法条命中情况不一致，不能按"命中其中一条"判定整体召回**

- Query：`"合同解除\n甲方可随时无理由解除本合同，无需提前通知，亦无需向乙方支付任何经济补偿或赔偿金。"`
- 相关法条（4条）：第八十七条、第四十七条、第四十八条、第四十六条，2个样本
- working口径Top5命中情况：
  - 第八十七条：Dense rank=9(未命中)，BM25 rank=1(命中)，RRF rank=3(命中)
  - 第四十七条：Dense rank=11(未命中)，BM25 rank=2(命中)，RRF rank=6(未命中)
  - 第四十八条：Dense rank=7(未命中)，BM25 rank=4(命中)，RRF rank=5(命中)
  - 第四十六条：Dense rank=2(命中)，BM25 rank=6(未命中)，RRF rank=1(命中)
- 按本场景实际recall@5计算：**Dense=1/4=0.25，BM25=3/4=0.75，RRF=3/4=0.75**（RRF在本场景巧合地等于BM25，但命中的是不同的法条组合，不是同一套）
- 判定：这正是指令要求的"不能仅因Top-K命中了其中一条，就认为该Query的全部相关法条均已召回"的典型例子——Dense对本场景4条法条只命中1条，看起来"有命中"但实际远未完整覆盖；BM25/RRF命中3/4但各自漏掉的是不同法条（BM25漏46条，RRF漏47条）。
- 标准答案核验状态：UNVERIFIED。
