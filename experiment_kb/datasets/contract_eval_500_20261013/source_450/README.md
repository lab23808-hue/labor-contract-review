# 劳动合同评测集扩展包（450份候选合成合同）

## 本包是什么
- `synthetic_contracts/`：450份由固定随机种子和模板脚本生成的**合成测试合同**。它们不是实际签署合同，不含真实个人身份证号或真实当事人信息。
- `manifest_450.csv`：每份合同的哈希、来源类别、模板家族、场景标签、划分及状态。
- `candidate_labels_pending_review.csv`：每份样本一个候选 query 与候选相关法条。所有标签均为 `pending_human_legal_review`，不得直接当作金标准指标。
- `official_template_source_catalog.csv`：官方公开劳动合同示范文本来源目录。这里列的是公开页面与附件链接，而不是已下载并核验的已签署合同。
- `dataset_summary.json`：数量、划分和限制。

## 数据边界
本轮公开来源调研找到的是政府部门发布的劳动合同示范文本（通用、劳务派遣、非全日制、行业简易等），没有找到足以证明可公开收集数百份完整已签署劳动合同的可靠开放来源。示范文本不等于真实履约合同。为了不编造“真实合同”，本包把450份新增文本全部明确标记为合成数据。

## 数据划分
- 总数450，开发集360，最终测试集90。
- 按 `template_family_id` 分组：TF01-TF24 为开发组，TF25-TF30 为最终测试组；同一家族不跨集合。
- 这只是初始分组；正式评测前仍需与现有50份的模板/条款原型做跨集合近重复检查。由于目前未对本包与现有项目本地数据运行指纹比对，不能宣称已排除与原有50份的重复。

## 标签使用规则
`candidate_relevant_law` 是按预设风险场景给出的候选依据，**不是法律专业审核结论**。请先由法律专业人员核验 query 和法条，再将 `verification_status` 更新为经过核验的状态，才能将它纳入正式检索指标。对范围复杂、可能涉及多条法律的场景，允许追加、删减或标记争议，不应为了检索表现强行保留候选标签。

## 公开官方范本来源（请保留出处）
参考 `official_template_source_catalog.csv`。政府页面对公众开放查阅/下载，但本次未核验所有附件的下载完整性及批量再发布许可。若要把范本正文直接放入可分发的数据包，先核实来源页面条款、文件版本与复用权限，并保存原文件哈希。

## 本包不做的事
- 未修改任何本地生产项目代码、正式知识库或 Chroma。
- 未将任何样本声称为真实合同。
- 未宣称450条候选法律标签已经经过人工核验。
- 未将本包自动合并进现有 `data/eval_samples/contracts/`。
